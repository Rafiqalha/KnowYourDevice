# KnowYourDevice 2.0 — Kenali perangkatmu, lebih dekat.

Unduh **KnowYourDevice-2.0.0-Windows-x64.exe**, kemudian klik dua kali. Aplikasi portable tidak memerlukan instalasi Node.js, Python, atau Electron secara terpisah.

Perlu **Windows 10/11 x64 dan .NET Framework 4.8**. Setelah diunduh, pemindaian dapat digunakan tanpa internet. EXE belum ditandatangani dengan sertifikat penerbit.

Perubahan utama:

- Antarmuka baru dengan komponen resmi shadcn/ui, ikon Lucide, latar krem, aksen terracotta, serta mode terang/gelap.
- Tipografi Lora & Inter berlisensi terbuka, dengan nuansa editorial terinspirasi Anthropic. Font khusus Anthropic tidak disertakan.
- Ringkasan CPU/RAM/storage, grafik penggunaan CPU/RAM dari sampel nyata, dan navigasi detail enam kategori.
- Pencarian lintas komponen, filter jenis perangkat, penjelasan fungsi komponen, dan status setiap sumber data.
- ID pribadi disembunyikan secara bawaan; pilihan privasi berlaku untuk tampilan dan ekspor HTML/JSON/CSV.
- Mesin deteksi C# tetap berjalan secara lokal. Renderer terisolasi dari Node.js dan akses filesystem langsung.

Pengujian lokal pada Windows 11 meliputi pemindaian hardware nyata, navigasi, pencarian, pengaturan privasi, ekspor melalui mesin native, tema, ukuran 1024 × 720, dan pemindaian ulang. Hasil di komputer lain bergantung pada firmware, driver, serta izin WMI. Dukungan Windows 10 ditargetkan tetapi belum diuji pada perangkat Windows 10 fisik.

Konektor fisik yang kosong, kemampuan USB-C/HDMI, VRAM besar melalui properti WMI legacy, serta sebagian sensor/kesehatan disk tetap memiliki batas deteksi. Aplikasi menjelaskan data yang kosong atau tidak dapat diakses dan tidak mengisi angka perkiraan.

`SHA256SUMS.txt` disertakan untuk memeriksa integritas file yang diunduh.
